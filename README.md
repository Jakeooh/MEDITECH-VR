# 🥽 MediTech-VR

**MediTech-VR** is a Virtual Reality-based educational mini-project designed to make learning human anatomy more interactive and immersive.

The application allows students to explore **3D models of human body parts in a virtual environment**, answer questions within VR, and interact with an **AI assistant** for additional learning support.

The project is mainly intended for students interested in or preparing for **medical and healthcare-related fields**.

## ✨ Features

* 🫀 Explore 3D human body parts in Virtual Reality
* 🥽 Mobile VR-based immersive learning experience
* ❓ Interactive question and quiz section within VR
* 🤖 Integrated AI assistant for learning support
* 🎓 Designed for anatomy and medical education
* 🌐 Uses web technologies for supporting functionality

## 🛠️ Technologies

* Mobile VR
* OpenXR
* Web Technologies
* Artificial Intelligence
* 3D Anatomical Models

## 🎯 Purpose

MediTech-VR explores how **Virtual Reality and AI can improve traditional anatomy learning** by allowing students to visualize anatomical structures in an interactive 3D environment rather than relying only on textbooks and 2D diagrams.
